# Changelog — startapus-browser

## 0.24.1 — процесс

### Добавлено

- **CI-гейт** `.github/workflows/gate.yml`: `npm install && npm run gate` на push/PR.
- **Регламент релиза** `docs/release.md`: обязательный гейт, живая проверка, порядок тегов,
  откат профиля, диагностика после релиза.

## 0.24.0 — фаза 3 закрыта

### Добавлено

- **Изоляция пикера:** каждый запуск получает нонс, payload обязан его вернуть; чужой/устаревший
  результат отклоняется, глобальная переменная очищается сразу после чтения.
- **`E_GUEST_GONE`**: отсутствие гостя сообщается агенту кодом с подсказкой, а не общим
  «guest не готов»; тест `SEC-3`.

### Решение (ADR-002)

Токен на `/client/*` **не вводим**: host не может проверить токен рендерера, а статический токен
читается локально. Вместо него — Origin-гейт (браузерная страница не подделает Origin),
POST-only, отсутствие CORS `*`, приватный `/health`. См. `docs/adr-001-owner-decisions.md`.

### Проверки

`SEC-2`, `SEC-3`, guard пикера в `check-client-imports`, `selftest 52/52`.

## 0.23.0 — фаза 3: безопасность маршрутов и данных

### Добавлено

- **Origin-гейт на изменяющих маршрутах:** `/client/poll`, `/client/event`, `/panic`, `/selftest`
  отклоняют запросы с чужим веб-Origin (`403 E_ORIGIN_FORBIDDEN`) и требуют `POST` (`405`).
  Браузерная страница больше не может управлять панелью через localhost.
- **CORS без `*`:** заголовок отдаётся только доверенному origin рендерера.
- **`/health` без приватных данных:** вместо списка сессий и URL — `sessionsCount` и `urlHost`.
- **Untrusted-конверт** для page-derived данных: `ui_read_page`, `ui_find`, `ui_console`,
  `ui_page_text`, `ui_network`, `ui_inspect`, `ui_guest_state` возвращают
  `{ trust: { untrusted, source, hash }, data }`.
- **Счётчики перезагрузок:** `panelMounts` (сколько раз монтировалась панель) и
  `counters.navigations`/`loadErrors` — теперь видно, кто инициирует перезагрузку.

### Проверки

`SEC-2` (403/405), `selftest 51/51`, `TOOLS 29`, `ENGINE 13/13`.

## 0.21.1 — фаза 1 закрыта

### Добавлено

- **Long-poll**: `/client/poll` держит запрос до 15 с (`wait: true` от панели), поэтому команда
  доходит без ожидания интервала опроса; без флага маршрут отвечает сразу (тесты и curl).
  Тест `POLL-1` (252 мс).
- **Сверка отпечатка сборки**: клиент присылает `clientRev` (из `__BUILD_REV__`), `/health`
  отдаёт `clientRev`/`revMatch`, `npm run live` падает при `revMatch: false`. Тест `REV-1`.

### Итог фазы 1

`destroyed`/`render-process-gone` с повторной резервацией (E13), `verify` по `commandId` (SEC-1),
атомарный стор, мьютекс тика, long-poll, сверка отпечатка — всё покрыто гейтами:
`SCRIPT 10/10 · RULES 8/8 · ENGINE 13/13 · IMPORTS OK · TOOLS 26 · selftest 47/47`.

## 0.21.0 — фаза 1: устойчивость

### Добавлено

- **Восстановление после падения гостя:** `render-process-gone`/`crashed`/`destroyed` сбрасывают
  гостя, увеличивают `recoveries` и пересоздают сессию с новой резервацией lease

  чужие/просроченные (`probe verify:stale`); тест `SEC-1`.

### Исправлено

- **Атомарная запись стора задач:** `tmp` + `rename`, обрыв не может усечь очередь.

## 0.1.0

### Добавлено

- Вкладка **Startapus Browser** в правой панели DSH (`sidebar.right.pane.tab`).
- Настоящий браузерный guest на Electron `<webview>` — без ограничений `<iframe>`
  (`X-Frame-Options`/CSP), с произвольными сайтами.
- Тулбар: назад, вперёд, обновить, адресная строка, кнопка выделения элемента.
- Пикер элемента `⌖`: подсветка под курсором, селектор в подсказке, `Esc` — отмена.
- Портрет выбранного элемента (селектор, тег, id/classes, размер, текст, URL).
- Вставка выбранного элемента агенту в композер как чип `ЭлементN` с
  модель-ориентированной сериализацией.
- Строка статуса панели: стадии `резервация → dom-ready → загрузка → загружено`,
  ошибки загрузки и падения guest-а видны без DevTools.

- Страница переживает переключение вкладок: `<webview>` хранится в модульном пуле,
  при уходе из панели элемент отцепляется, при возврате — переподключается
  (сохраняются скролл, введённые данные и история).
- Внизу панели только короткая строка статуса; полный портрет элемента в панель
  не печатается — он уходит агенту через чип.

### Технические решения

- DSH создаёт главное окно с `webviewTag: true`, поэтому `<webview>` доступен.
- Guest подключается только с резервацией из ядра: `window.dshDesktop.browser
  .acquire(workspace)` → `{ lease, partition }`; элемент получает `name=lease`,
  `partition`, `src=about:blank#<lease>` и `data-sidebar-browser-frame`.
- Ядро стирает `preferences` гостя перед attach, поэтому preload недоступен:
  пикер внедряется через `webview.executeJavaScript`.
- Пикер не возвращает значение напрямую (Electron не клонирует объект ошибки →
  `An object could not be cloned`), а паркует результат в `window.__startapusPick`;
  панель опрашивает простое значение.
- Lease одноразовый: при отсутствии `dom-ready` за 4 с панель освобождает
  резервацию и берёт новую.
- Клиентский бандл — CJS-фабрика внутри `window.__ModuleLoader__.load({ id, factory })`,
  как у штатных клиентских плагинов DSH.
- `peerDependencies` без пинов `@deepseek-ai/dsh-*`, иначе DSH блокирует плагин
  как несовместимый.

### Известные ограничения

- История и куки живут в partition `startapus-browser` (не общие с штатным браузером DSH).
- Загрузки файлов и всплывающие окна ограничены политикой ядра.
