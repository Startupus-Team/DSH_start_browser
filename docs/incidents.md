# Журнал инцидентов (живая эксплуатация)

Правило: каждый дефект из живой работы получает запись «симптом → причина → фикс → тест».
Тест обязателен: если инвариант нельзя проверить офлайн — добавляется проверка в `npm run live`
или `scripts/soak.mjs`.

| # | Симптом | Причина | Фикс | Тест |
|---|---|---|---|---|
| 1 | `WebView must be attached to the DOM and the dom-ready event emitted…` при вводе адреса | `loadURL` вызывался до `dom-ready` | `pendingUrl`: адрес применяется на `dom-ready` | `E14` |
| 2 | `ui_act`/`ui_select`/`ui_screenshot` падали той же ошибкой | команды выполнялись на недозрелом госте | `readyView(command)`: ожидание готовности адресованной вкладки | `E15` |
| 3 | `acquires: 214, releases: 0`, панель мигала | при падении гостя сессия удалялась без `release` lease | `releaseLease()` во всех путях (закрытие, падение, зомби) | `E16` |
| 4 | то же мигание продолжалось после фикса 3 | бюджет восстановления сбрасывался вместе с сессией | журнал потерь на вкладку + `E_GUEST_LOOP` (3 падения/10 с) | `E17` |
| 5 | пересоздание после `render-process-gone` возвращало цикл | контракт ядра: на падение рендерера вкладка **закрывается** | закрываем вкладку, lease освобождаем, `counters.crashes` | `E13` |
| 6 | гость не подключался вообще (`attachFailures`, нет `dom-ready`) | pane смонтирован скрытым: `div(0x0)` в цепочке предков | реконсиляция по видимости (`setPaneState`), гость только у видимой панели | `E18` |
| 7 | «гость этой вкладки не создан» после ввода адреса | `openInSession` брал `activeGuest()` — гостя **чужой** вкладки | навигация строго `sessions.get(tabId)` | `E19` |
| 8 | адрес терялся, если гость ещё создавался | `loadURL` некуда применить | `requestedUrl` перекрывает стартовый адрес | `E19` |
| 9 | `ui_console` отдавал пустые сообщения | payload `console-message` читался только из `event.detail` | читаем и `detail`, и поля события | — (проверено вживую) |
| 10 | ложная «ошибка загрузки 0» в статусе | `did-fail-load` с кодом 0 / подфреймы считались провалом | игнорируем `0`, `-3`, `isMainFrame === false` | — |
| 11 | подсказка `⌘T` стояла текстом, а не справа | карточка guide не имела `commandId`, строка ярлыка — другой id | `commandId` == id строки каталога; проверка `/health.shortcutState` | `live-check` |
| 12 | вкладки закрылись без причины | мой ошибочный вызов `/panic` при сбросе счётчиков | `/panic` теперь POST-only и не используется для диагностики | `SEC-2` |
| 13 | падение рендерера могло подняться само | реконсиляция создавала гостя после закрытия | упавшая вкладка удерживается до кнопки «Восстановить» | `E20` |

## Открытые ограничения

- **Активация вкладки из плагина невозможна** — запрос к ядру: `docs/kernel-request.md`.
  Канонический вход: `⌘T` (команда `startapus-browser.new`), вкладку активирует ядро.
- Скрытая панель не подключает `webview` — поэтому «гость создастся, когда её покажут».
- Сторонние cookie DSH копятся по одному на запуск — `scripts/dsh-cookie-doctor.mjs`,
  минимизируем рестарты.
